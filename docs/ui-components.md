## Forms

Die Anwendung verwendet Flask-WTF und Bootstrap Form Controls für:

- Registrierung
- Login
- Profil bearbeiten
- Post erstellen
- Post bearbeiten
- Suchfunktion

---

## Buttons

Verwendete Bootstrap Buttons:

- `btn-success`
  - Registrieren
  - Post veröffentlichen
  - Post schließen

- `btn-primary`
  - Login
  - Suche

- `btn-danger`
  - Logout
  - Post löschen

- `btn-warning`
  - Post bearbeiten

- `btn-outline-secondary`
  - Aufklappbare Detailansicht

## Tooltips

Bootstrap Tooltips wurden eingesetzt, um zusätzliche Informationen bereitzustellen.

Beispiele:

- Verlustdatum
- Verlustort

Dadurch bleibt die Oberfläche übersichtlich und Nutzer erhalten Informationen nur bei Bedarf.

---

## Cards und Collapse Components

Bootstrap Cards und Collapse Components werden verwendet, um Suchanzeigen platzsparend darzustellen.

Funktionen:

- Anzeige von Titel und Benutzername
- Aufklappbare Detailansicht
- Beschreibung
- Verlustort
- Verlustdatum

---

## Flash Messages

Für Benutzerfeedback werden Flash Messages genutzt.

Beispiele:

- Registrierung erfolgreich
- Login fehlgeschlagen
- Post erfolgreich erstellt
- Validierungsfehler
