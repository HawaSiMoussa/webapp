# Solution Elements

## Proposed Solution

LostAndFound ist eine digitale Plattform für die HWR Berlin, auf der Studierende und Mitarbeitende verlorene Gegenstände melden und wiederfinden können.

---

## Core Features

### Suchanzeige erstellen

Nutzer können verlorene Gegenstände mit Titel, Beschreibung, Verlustort und Verlustdatum veröffentlichen.

### Campusbezogener Feed

Es werden nur relevante Anzeigen des jeweiligen Campus angezeigt.

### Kontaktaufnahme

Suchende können über die Plattform miteinander in Kontakt treten.

### Statusverwaltung

Das Fundbüro kann den Status einer Suchanzeige aktualisieren.
