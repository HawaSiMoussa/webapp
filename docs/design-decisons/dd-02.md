# DD-02: Begrenzung auf eine aktive Suchanzeige pro Nutzer(Meine Top DD)

## Meta

Status
: Decided

Updated
: 23-Jun-2026

## Problem Statement

Ein Nutzer könnte mehrere aktive Suchanzeigen gleichzeitig erstellen. Dadurch würde der Feed unübersichtlich werden und einzelne Nutzer könnten viele Beiträge gleichzeitig veröffentlichen.

## Decision

Es wurde entschieden, dass jeder Nutzer nur eine aktive Suchanzeige gleichzeitig besitzen darf.

Vor dem Erstellen eines neuen Posts wird geprüft, ob bereits eine laufende Suchanzeige existiert. Die Entscheidung wurde von Fatme Berjaoui umgesetzt.

## Regarded Options

### Option 1: Unbegrenzte Anzahl aktiver Anzeigen

**Vorteile**
- Maximale Flexibilität.

**Nachteile**
- Gefahr von Spam.
- Schlechtere Übersichtlichkeit.

### Option 2: Eine aktive Anzeige pro Nutzer (gewählt)

**Vorteile**
- Überschaubarer Feed.
- Verhindert Mehrfachanzeigen.
- Erleichtert die Verwaltung durch das Fundbüro.

**Nachteile**
- Nutzer müssen eine Anzeige schließen, bevor sie eine neue erstellen können.
