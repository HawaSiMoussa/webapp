# DD-04: Email HWR für das Login und die Registrierung

## Meta

Status
: Decided

Updated
: 23-Jun-2026

## Problem Statement

Die Plattform muss vor externen Zugriffen geschützt werden, indem nur verifizierte HWR-E-Mail-Formate zugelassen werden.

## Decision

Für die Validierung der E-Mail-Adresse werden drei spezifische Endungen genutzt, die direkt bei der Eingabe überprüft werden. Wenn der User sich anmeldet oder registriert, muss die Adresse zwingend auf `@stud.hwr-berlin.de`, `@dot.hwr-berlin.de` oder `@hwr-berlin.de` enden. Um diese Überprüfung überhaupt zu ermöglichen, wurde ein extra E-Mail-Paket sowie ein Validator installiert, die sicherstellen, dass die Eingabe einer korrekten E-Mail-Form entspricht. Erst wenn diese Kriterien erfüllt sind, kann sich der User erfolgreich im System anmelden.

## Regarded Options

### Option 1: beschränkter Hwr zugriff

**Vorteile**
- Hohe Plattform-Sicherheit
- Verhindert Fremdzugriffe verlässlich

**Nachteile**
- Zusätzliche Paket-Abhängigkeit

### Option 2: Offene E-Mail-Registrierung

**Vorteile**
- Keine Einschränkungen

**Nachteile**
- Erhöhtes Spam-Risiko
- Kein HWR-Bezug
