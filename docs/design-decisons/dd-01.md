# DD-01: Validierung des Verlustdatums

## Meta

Status
: Decided

Updated
: 23-Jun-2026

## Problem Statement

Benutzer könnten versehentlich ein Verlustdatum eingeben, das in der Zukunft liegt. Dadurch würden fehlerhafte Suchanzeigen entstehen.

## Decision

Es wurde entschieden, eine Validierung einzubauen, die verhindert, dass ein Verlustdatum nach dem aktuellen Datum liegt.

Diese Entscheidung verbessert die Datenqualität und wurde von Fatme Berjaoui umgesetzt.

## Regarded Options

### Option 1: Keine Prüfung

**Vorteile**
- Einfache Implementierung.

**Nachteile**
- Falsche Daten möglich.
- Unglaubwürdige Suchanzeigen.

### Option 2: Prüfung gegen das aktuelle Datum (gewählt)

**Vorteile**
- Höhere Datenqualität.
- Verhindert Fehleingaben.

**Nachteile**
- Zusätzlicher Validierungsaufwand.
