# DD-03: Die Suche im Feed

## Meta

Status
: Decided

Updated
: 23-Jun-2026

## Problem Statement

Das manuelle Durchsuchen des Feeds durch ständiges Scrollen ist für den User ineffizient und unkomfortabel.

## Decision

Die Suche im Feed wurde implementiert, damit der User gezielt nach einem Post suchen kann und nicht ständig nach unten scrollen muss, um alles manuell zu durchsuchen. Dabei wurde die Suche extra so gestaltet, dass sie für den User besonders einfach und komfortabel ist. Groß- und Kleinschreibung spielen keine Rolle. Dadurch wird verhindert, dass der User verwirrt wird oder fälschlicherweise denkt, es gäbe keine passenden Posts, nur weil der eingegebene Suchbegriff nicht zu 100 % exakt mit dem Titel übereinstimmt.

## Regarded Options

### Option 1: Text suche 

**Vorteile**
- Keine Verwirrung mehr
- Extrem schnelle Ergebnisse

**Nachteile**
- Komplexe SQL-Abfrage

### Option 2:  exakte Suche

**Vorteile**
- Schneller programmiert

**Nachteile**
- Findet seltener Ergebnisse
- Frustriert den User
