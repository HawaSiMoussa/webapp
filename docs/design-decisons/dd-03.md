# DD-01: Besonderheiten beim Admin

## Meta

Status
: Decided

Updated
: 23-Jun-2026

## Problem Statement

Der Admin soll nicht so wenig rehcte haben wie normale user. 
## Decision

Der Admin kann alle Posts sehen, unabhängig davon, von welchem Campus sie stammen, und er hat das Recht, diese Posts zu löschen. Eigentlich war zusätzlich geplant, eine Funktion einzuführen, mit der der Admin mehrere Posts parallel erstellen kann. Dies hat jedoch leider nicht geklappt, da es zu mehreren Komplikationen bei der Durchführung der App kam, sobald versucht wurde, den Admin aus dem gesetzten Filter von Fatme für normale User auszuschließen. Zum Glück kann der Admin aber alle gewünschten Posts löschen, da wir der festen Meinung sind, dass ein Admin keine Posts unnötig löschen würde.

Diese Entscheidung verbessert die Datenqualität und wurde von Hawa Si Moussa umgesetzt.

## Regarded Options

### Option 1: Admin löscht kommentare 

**Vorteile**
- admin kann falsche oder unnötige posts löschen

**Nachteile**
- admin muss zu viel machen


### Option 2: admin kan ale posts sehen egal welcher campus
**Vorteile**
- hat übersicht und access zu allem 

**Nachteile**
- admin sieht zu viel und es wird unübersichtlich
