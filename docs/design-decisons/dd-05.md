# DD-02: Registrierung und Login Rückmeldung

## Meta

Status
: Decided

Updated
: 23-Jun-2026

## Problem Statement

User benötigen klares Feedback und einen schnellen Registrierungsprozess ohne unnötige Hürden oder Sicherheitsrisiken.

## Decision

Es wurde ein direktes Feedback eingeführt, das heißt, dass bei der Registrierung eine Benachrichtigung ausgegeben wird, falls man versucht, sich mit einer bereits vergebenen E-Mail-Adresse anzumelden. Ebenso erhält man beim Login eine Rückmeldung, wenn die eingegebene E-Mail noch gar nicht im System registriert ist. Um das System benutzerfreundlicher zu gestalten und Zeit zu sparen, wird der User nach der Registrierung und dem Ausfüllen des Kontaktformulars direkt zur Home-Seite weitergeleitet, ohne sich ein weiteres Mal verifizieren zu müssen. Zudem ist das Passwortfeld auf eine Mindestlänge von 8 Zeichen begrenzt, um die Konten abzusichern, wobei der User explizit darauf hingewiesen wird, falls sein Passwort zu kurz ist. Ein User darf sich nur ein einziges Mal mit seiner E-Mail registrieren, da eine mehrfache Nutzung den Rahmen sprengen und zu Spam sowie Missbrauch führen würde.

## Regarded Options

### Option 1: Direktes Feedback und Weiterleitung

**Vorteile**
- Hohe Benutzerfreundlichkeit
- Spart viel Zeit
- Verhindert Missbrauch effektiv

**Nachteile**
- Höherer Entwicklungsaufwand

### Option 2: passwort ab 8 zeichen 

**Vorteile**
- verhindert kurze einfahc passwörter

**Nachteile**
- erfordert vielleicht mehr gednaken zum passwort
