# Project Name: LostAndFound
Dinge gehen verloren.
LostAndFound bringt sie zurück. Unser Projekt LostAndFound ist eine Webanwendung, die Studienerende an der HWR und Fundbüros miteinander verbindet, um verlorene Gegenstände durch eine zentrale Plattform schnell und effizient wiederzufinden.

## Vorraussetzungen, um die WebApp zu starten
 - Python version: Python 3.14
 - In Vs Code angemeldeter GitHub Account
 
 ## WebApp starten
 - git clone des Repository
 - benötigte packages (aufgelistet in der requirements.txt)herunterladen mit dem Befehl:
    pip install -r requirements.txt
    - Anwendung bzw. Flask starten im Terminal:
    python app.py
    - über http://127.0.0.1:5000 die Anwendung in einem Browser starten
